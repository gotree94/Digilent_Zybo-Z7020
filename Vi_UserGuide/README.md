## 1. Vi / Vim 소개
- **Vi**는 대부분의 Unix/Linux에 기본 포함된 텍스트 편집기  
- **Vim**은 Vi Improved(향상된 Vi)  
- 많은 개발자/시스템관리자가 사용하는 필수 툴

실행:
```bash
vi filename.txt
vim filename.txt
```

종료:
```text
:w
:q
:wq
:q!
```
