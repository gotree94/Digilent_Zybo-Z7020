## ⚠️ 알려진 제약사항

### I2C 접근 문제
**문제**: Zybo Z7-20의 SSM2603 I2C는 PS MIO50/51에 연결
**영향**: 순수 FPGA 프로젝트에서 I2C 직접 접근 불가
**해결책**:
1. ✓ 코덱 사전 초기화 방법 문서화
2. ✓ Pmod 점퍼선 연결 방법 제공
3. ✓ 프로젝트 2/3 사용 권장

### 클럭 주파수 오차
**문제**: 125MHz에서 정확한 12.288MHz 생성 어려움
**영향**: 1.7% 샘플레이트 오차
**평가**: 대부분 애플리케이션에서 허용 가능
**고급 옵션**: PLL/MMCM 사용 가능 (문서화됨)

## ✅ 테스트 시나리오

### 시나리오 1: 프로젝트 2 초기화 후 사용
```bash
1. 프로젝트 2 실행 → I2C 초기화
2. 전원 유지
3. 프로젝트 1 비트스트림 로드
4. 오디오 루프백 작동 확인
```
**예상 결과**: ✓ 작동

### 시나리오 2: 순수 FPGA만 사용
```bash
1. 프로젝트 1만 로드
2. I2C 초기화 실패 (LED0 꺼짐)
3. 코덱은 기본 설정으로 작동
```
**예상 결과**: △ 제한적 작동 (일부 기능만)

### 시나리오 3: Pmod 점퍼선 연결
```bash
1. Pmod JE1, JE2를 I2C에 물리적 연결
2. 프로젝트 1 로드
3. I2C 초기화 성공 (LED0 켜짐)
```
**예상 결과**: ✓ 완전한 작동 (고급 사용자)
